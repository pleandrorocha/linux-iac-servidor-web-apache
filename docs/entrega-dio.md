# Entrega DIO

**Nome sugerido do repositorio:** `linux-iac-servidor-web-apache`

**Link depois da publicacao:** https://github.com/pleandrorocha/linux-iac-servidor-web-apache

## Descricao para colar na plataforma

Desenvolvi um projeto pratico de Infraestrutura como Codigo (IaC) para provisionar automaticamente um servidor web Apache2 no Ubuntu utilizando Bash Script.

A automacao instala os pacotes necessarios, prepara um diretorio dedicado, publica uma pagina HTML de exemplo, configura um VirtualHost na porta 80 e inicia ou reinicia o servico. O projeto tambem oferece um modo de simulacao, verificacao de sintaxe, teste de resposta HTTP 200 e documentacao de instalacao, diagnostico e uso.

Tecnologias utilizadas: Linux, Ubuntu, Bash, Apache HTTP Server, HTML, Git, GitHub e GitHub Actions.

Este projeto reforca conhecimentos de administracao Linux, automacao e provisionamento, hospedagem de sites, validacao de servicos e versionamento de codigo. A implementacao foi elaborada para laboratorio e pode ser adaptada para ambientes de maior complexidade.

> Antes da entrega, execute o projeto no seu ambiente e confirme a publicacao no GitHub. Nao declare testes realizados se nao os executou.
